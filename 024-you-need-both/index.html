Voice

How it talks

Direct
Start with what matters. Cut the preamble. Respect people's time and intelligence.
Transparent
Name the friction. Acknowledge trade-offs. Confidence comes from honesty, not polish.
Accessible
No jargon without a plain-English definition. Technical rigor, human delivery.
Warm
Serious about craft, never cold. The work is rigorous. The way we talk about it is not.
